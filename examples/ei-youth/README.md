## 这个例子重点看什么

1. 标记是模型估计的门控变量比值，不等于直接测得的真实生理 E/I。
2. 年龄关系的分析单位是年龄组；脑区空间相关不能改写为个体预测准确率。
3. 药理敏感性、拟合质量和跨队列认知关联分别支持不同层次的结论。
4. 四模块共用来源，综述不重复检索表，评议不把未读补充材料说成作者没有做。
